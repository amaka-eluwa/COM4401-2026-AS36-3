# 🍕 Pennine Pizza Works – Pizza Ordering System

**Team 3 · COM4401 Software Engineering Fundamentals · Mini Project 2**

A Flowgorithm program that calculates the cost of a pizza order and prints a personalised, itemised bill. The full analysis, design, build and testing are in the project report.

## How to run it

**You need:** [Flowgorithm](http://www.flowgorithm.org) (free).

1. Download `PennineFlowgorithm_Final_Version.fprg` from the `Flowgorithm_System` folder.
2. Open Flowgorithm, choose **File › Open** and select the file.
3. Press **Run** and answer each question in the console, pressing **Enter** after each one.
4. The itemised bill is printed at the end.

## Versions

The program was built in stages (V1 to V4), then finalised after testing. See the [Team Work Allocation](Team_Contribution_Record/Team_Work_Allocation_Software.md) for who built each version.
