# Database Report

## Data Integrity

The database was designed to maintain accurate, consistent and valid data through the use of appropriate table structures, data types and relationships between tables.

Primary keys are used to uniquely identify records within the database and prevent duplicate identifiers. Foreign keys are used where tables are related, ensuring that records reference valid records in the related table.

Appropriate data types are used for different types of information, such as text, numbers and monetary values. This helps reduce the risk of invalid data being entered into the database.

The relationships between the tables also help maintain consistency. For example, workstation and hardware records can be linked through the appropriate identifiers rather than repeatedly storing the same information. This reduces duplication and helps ensure that related information remains consistent.

The SQL queries were tested using the database created for the project. The working SQL statements and their results are included as portfolio evidence in the `Screenshots` folder.
