The network we made was a client-server network. this is evident as all PCs connect to a single switch in the model.
this was chosen as all the PCs could connect to the office server without affecting each other if one of the broke down.

some of the protocols used in the network were IP, HTTP, and ICMP.

IP (Internal Protocol) was used to give each PC and server a unique P address. this allows all of the to communicate with
each other without getting mixed up. we also configured subnets and gateways to group them up depending on if the connected
to the cloud server or the office server.

HTTP (Hyper-Text Transfer Protocol) was use to have web page searching in the browser. HTTPS (Hyper-Text Transfer Protocol
Secure) would be preferred as it have much safer searching, however that is unable to be used in Filius.

ICMP (Internal Control Message Protocol) was used to ping the PCs and servers. Ping (Packet Internet Groper) checks whether
a PC or server is available and operational. it does this by working out the latency (time taken between sending and receiving).
